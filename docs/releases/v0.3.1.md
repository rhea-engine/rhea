# Rhea v0.3.1 — Ceto asset previews

Ceto can start with no world loaded and open Rhea scenes or preview glTF,
GLB, and OBJ assets directly. Use the Open browser to browse for content, or
enter a local or remote address in the address bar and press Enter.

The portable Windows x64 package is named `Ceto-0.3.1-windows-x64.zip`.
Extract the complete archive and start `Ceto.exe`. To try a bundled Rhea
world, open **Samples → Courtyard → world.scene**.

## Viewing assets

- Direct glTF and GLB previews preserve the imported node hierarchy and
  transforms. OBJ previews can load referenced materials and textures.
- Drag with the left mouse button to orbit the asset and use the mouse wheel
  to zoom. **Focus** fits the asset in view and **Reset** restores its initial
  view.
- The Animations panel lists playable skeletal clips by item. Use **Play**
  and **Pause** to control playback. Starting another clip on the same item
  replaces the previous clip.
- The action bar displays the current address and provides access to Open,
  Focus, and Reset.

## Engine and compatibility

- Mesh bounds and camera controls support fitting assets in the viewport.
- Prepared scene instances preserve child order so GUI rows and columns
  follow their scene definitions across platforms.
- OBJ preparation completes once when a scene supplies an explicit material
  file. This fixes missing meshes when opening affected scenes.
- Ceto previews skeletal animation. glTF node transforms can be imported as
  static transforms. Animated node transforms, morph targets, and material
  properties such as `KHR_animation_pointer` are outside the supported
  playback scope.

Rhea remains experimental. Rebuild applications against the matching engine
revision. The downloadable package targets Windows x64. The World1 scene
was also checked under Linux/WSL with both local and web sources.
