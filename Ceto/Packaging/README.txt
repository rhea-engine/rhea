Ceto scene viewer
=================

Extract the complete ZIP before starting Ceto.exe. Keep the Data directory
next to the executable. No command-line arguments are needed.

In the Open browser, select Samples, open Courtyard, and open world.scene.
See Data/samples/Courtyard/README.md for controls and suggested scene changes.

Your own scenes can be opened through the file browser.
