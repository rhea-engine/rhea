# Rhea v0.1.0-alpha.1

Rhea’s first public alpha introduces a modular C++17 framework for building immersive 3D applications and virtual worlds.

This release is intended for C++ developers who want to explore the engine, build applications, and provide early feedback. Rhea is experimental: APIs, scene formats, and build configuration may change between releases, and backward compatibility is not guaranteed.

## Included in this release

- The Rhea runtime and its modular Fabric architecture.
- The Poseidon rendering layer, with Direct3D 11 and OpenGL backends.
- Integrations for physics and audio.
- BasicApp, a small example demonstrating a scene, camera, lighting, and a textured cube.
- Ceto, an experimental viewer for user-provided scenes.

An editor is not included.

## Tested configurations

The engine and BasicApp have been built and run in these configurations:

| Environment | Graphics backend |
|---|---|
| Windows | Direct3D 11 |
| Windows | OpenGL |
| Linux under WSL | OpenGL |

Native Linux installations and macOS have not been validated for this release.

## Getting started

Start with the instructions in `docs/GETTING_STARTED.md` to build and run BasicApp. BasicApp is the recommended introduction and does not require an editor or an external scene package.

For architecture, dependencies, and integration into your own CMake project, see the repository README.

## Ceto scene viewer

Ceto runs existing scenes, but this release does not include a demonstration scene.

When using your own scene assets, launch Ceto with:

```text
Ceto -d <directory>
```

This selects the directory used for the `//local/` virtual asset path.

A complete walkthrough for authoring and opening Scene-Files is planned for a subsequent documentation update.

## Known limitations

- The engine is under active development and is not presented as production-ready.
- No editor is included; application development currently uses C++ and asset/configuration files.
- Scene authoring documentation is incomplete.
- Platform validation is limited to the configurations listed above.
- Features beyond the BasicApp workflow may require additional setup and experimentation.

## Feedback

Bug reports and feedback are welcome through the repository’s issue tracker. Please include the engine version, operating system, graphics backend, reproduction steps, and relevant logs.
