# Security Policy

We value the security of our users and appreciate your efforts to responsibly disclose vulnerabilities.

## Reporting a Vulnerability

If you have identified a security vulnerability in this repository, please use the GitHub Security Advisory **Report a vulnerability** tab. 
Reports submitted this way are private and visible only to the reporter and authorized maintainers.

Alternatively, send a report to **dev@rhea-engine.org**.

Rhea is experimental and under active development. Security fixes are provided for the current default branch and, where practical, the latest public release.

Please do not report security vulnerabilities through public GitHub issues.

Send reports to **dev@rhea-engine.org** with:

Please include the affected component and version, a description of the impact, and the steps needed to reproduce the issue.

Please allow reasonable time to investigate and address the issue before public disclosure. 
The maintainers will attempt to acknowledge reports within seven days but cannot guarantee a fixed response or resolution time.

Reports involving bundled dependencies or Rhea’s integration of third-party software are also welcome.

Rhea does not currently operate a bug bounty program.
